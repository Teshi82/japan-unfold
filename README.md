# JAPAN, UNFOLD

A multilingual guide to Japan, with 11 languages and 12 language options, including Simplified and Traditional Chinese.

**Website:** https://teshi82.github.io/japan-unfold/

This repository serves the compiled static site directly from the root via GitHub Pages. It includes destination discovery, search and filters, favorites saved in the visitor's browser, and useful Japanese phrases. It does not require a user account or send favorites to a server.

## Source and development

Download `source-code.zip` for the editable React and Vite source. After extracting, run `npm install`, then `npm run dev`. Run `npm run build` to produce the static site in a sibling `dist` folder. Copy the files at the root of `dist` to this repository's root to update the published site. Do not remove this README or `source-code.zip` when updating.

## Content and photography

Destination details link to official visitor guides. Photos are used under the [Unsplash License](https://unsplash.com/license); photographers and source links are listed in the app. Translations are a first draft and have not been professionally reviewed.
